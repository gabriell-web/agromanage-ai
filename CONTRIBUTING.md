# Como contribuir

Para mudanças de código ou documentação, crie uma branch com um nome descritivo, faça commits pequenos e abra um pull request explicando o que mudou e como verificar. Use as issues para acompanhar melhorias e dúvidas.

Atualize a documentação quando o comportamento ou o escopo mudar. Use dados fictícios nos exemplos e nos testes. Preserve os dados dos participantes da pesquisa em sua fonte autorizada.
