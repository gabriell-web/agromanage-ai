# AgroManage AI

Projeto acadêmico do Lab-IA Sertão Twin, na UNIVASF em Salgueiro–PE. O AgroManage AI investiga como facilitar o registro e a consulta de despesas de atividades agrícolas, incluindo o acompanhamento de gastos em parcerias de produção.

## Situação do projeto

O repositório reúne a estrutura inicial e as decisões do protótipo. A primeira demonstração prevê registrar e consultar despesas de uma atividade, corrigir um lançamento e conferir o total. O acesso compartilhado entre parceiros é uma proposta a validar em campo.
